## Welcome!

This is my GitHub page for personal projects and studies.

I am an Information Systems student at UTFPR in Curitiba, Brazil, and I currently work as a firmware developer for embedded systems.

**IOT_Fish_Tank** is a project I am currently revisiting. I originally developed its firmware in 2023 and am now rebuilding it with a broader understanding of embedded systems, aiming for a more refined system and better-organized code.

**Estudos-CMSIS** is a collection of small projects exploring functionality I often encounter when developing firmware for microcontrollers. Here, I use CMSIS to gain a deeper understanding of how the code I write interacts with the hardware. Since these projects are primarily intended for learning, I write the code without AI tools and include detailed comments.

**Candle_Generator** was my first complete web project, developed in 2023 to learn how distributed systems work. It was built with Node.js and is probably outdated by now.

Progress on these projects will likely be slow, as I work on them in my free time.

Thanks for stopping by.  
Happy coding!
